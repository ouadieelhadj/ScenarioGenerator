# Way4 Knowledge Base — Instructions permanentes

## Reprise obligatoire

Au début de chaque nouvelle session travaillant dans ce projet :

1. Lire entièrement `CONTEXTE_REPRISE_SESSION.md`.
2. Inventorier les fichiers déjà présents dans `03_Guides`.
3. Comprendre les travaux terminés, les limites connues et les points bloqués.
4. Ne jamais recréer un guide existant : le relire et l'enrichir.
5. Attendre la demande précise de l'utilisateur avant de créer ou modifier un fichier.

## Répertoires

- Racine du projet : `E:\Way4-Knowledge-Base`
- Sources : `01_Source_Documents`
- Manuels anglais : `01_Source_Documents\manuals\english`
- Guides produits : `03_Guides`

## Règles documentaires

- Traiter tous les documents de `01_Source_Documents` en lecture seule.
- Ne jamais modifier, déplacer ou supprimer un manuel source.
- Ne jamais inventer une information Way4.
- Signaler explicitement toute information absente, ambiguë ou contradictoire.
- Recouper les différents manuels lorsqu'ils couvrent une même procédure.
- Citer les documents sources et, lorsque cela est possible, les pages utilisées.
- Toujours distinguer Desktop Client et Workbench Web.
- Préciser l'interface, les menus, les écrans, les champs, les vérifications et les différences entre interfaces.
- Organiser les guides par domaines et non comme de simples résumés des manuels.

## Première réponse d'une nouvelle session

Après lecture du contexte, résumer brièvement :

- l'objectif du projet ;
- les guides existants ;
- les travaux terminés ;
- les points incomplets ou bloqués ;
- la prochaine tâche possible.

Ne modifier aucun fichier pendant cette vérification initiale.
